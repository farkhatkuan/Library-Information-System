# Кітапхана ақпараттық жүйесі — Use Case

## 1. Жүйенің пайдаланушылары

- Оқырман
- Кітапханашы
- Жүйе әкімшісі
- Кітапхана басшылығы

## 2. Негізгі Use Case сценарийлері

**UC-01 — Жүйеге кіру**

Пайдаланушы логин мен құпиясөз арқылы жүйеге кіреді.

**UC-02 — Кітапты іздеу**

Оқырман немесе кітапханашы кітапты атауы, авторы және санаты бойынша іздейді.

**UC-03 — Кітапты алуға сұраныс беру**

Оқырман кітапты таңдап, оның қолжетімділігін тексереді және бронь жасауға сұраныс береді.

**UC-04 — Кітап беруді тіркеу**

Кітапханашы оқырманға кітап беру операциясын тіркейді.

**UC-05 — Кітапты қайтаруды тіркеу**

Кітапханашы қайтарылған кітапты тіркеп, оның мәртебесін жаңартады.

**UC-06 — Кітап қорын басқару**

Кітапханашы кітаптарды қосады, өзгертеді және есептен шығарады.

**UC-07 — Пайдаланушылар мен рөлдерді басқару**

Жүйе әкімшісі пайдаланушылардың есептік жазбалары мен рөлдерін басқарады.

**UC-08 — Есеп қалыптастыру**

Кітапхана басшылығы кітап қоры, берілген кітаптар және қызмет көрсету статистикасы бойынша есептерді қарайды.

**UC-09 — Кітап қолжетімділігін тексеру**

Жүйе кітаптың қолжетімділігін автоматты түрде тексереді.

**UC-10 — Хабарлама жіберу**

Жүйе оқырманға сұраныс нәтижесі және кітаптың қайтару мерзімі туралы хабарлама жібереді.

## 3. Қорытынды

Use Case сценарийлері кітапхана ақпараттық жүйесінің негізгі функцияларын және пайдаланушылардың жүйемен өзара әрекеттесуін сипаттайды.
