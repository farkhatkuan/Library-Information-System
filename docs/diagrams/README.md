# Кітапхана ақпараттық жүйесінің диаграммалары

Бұл папкада кітапхана ақпараттық жүйесінің UML және BPMN диаграммалары сақталады.

## Диаграммалар
- AS-IS BPMN — кітап берудің бастапқы процесі.
- TO-BE BPMN — автоматтандырылған кітап беру процесі.
- Use Case Diagram — пайдаланушылар мен жүйе функциялары.
- Sequence Diagram — кітап беру операциясының орындалу реті.
- Class Diagram — жүйенің негізгі кластары және байланыстары.
